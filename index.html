2025 / HGRID01 / 04
2025 / SOFTWARE ENGINEERING / HGRID

A hospital. A lot of paperwork. A better way.

At HGrid, I worked on a healthcare financing app. The agreement workflow took hours of manual work: pulling information together, populating documents, and sending them out. I automated that process with PDF parsing and the DocuSign API, and integrated credit bureau data into the financing logic. The part I'm proudest of isn't the API integration; it's that staff could get the job done in about 20 seconds.

3–4 HOURS → ~20 SECONDS BACKEND + WORKFLOW AUTOMATION
2025–26 / RESEARCH / RARE LAB

Then I had to teach a robot when to be quiet.

Bloom, our companion robot, was supposed to have natural conversations. But a small thing mattered enormously: when silence meant the user was done, and when the robot should wait to hear its wake word again. I built speech pipelines and interaction state, ran real-time YOLO object detection on a Raspberry Pi, and later built gRPC communication that lets a robot send camera context and task requests to a planner. That work became part of three research papers. Building for a person feels different when the software has a voice and a body.

STT / TTS / YOLO VISION gRPC + ROBOT PLANNING
2026 / CYBERSECURITY / CYBER FLORIDA

An alert isn't an answer.

In security operations, the interesting part is rarely a bright red alert on its own. It's the investigation afterward: what did the host connect to, what else happened, and is this something that needs blocking, escalation, or user outreach? I investigate suspicious traffic and malware activity, work through simulated attacks from first access to later stages, and have contributed to two published threat advisories.

SOC TRIAGE INCIDENT INVESTIGATIONS
2026 / SIDE PROJECTS / THE OVERLAP

Now those experiences keep colliding.

My favorite projects use lessons from all three worlds. ContractMap, which placed 3rd of 81 teams in Sperry Tech’s ShellHacks challenge, needed useful AI, solid backend design, and an agent that asks before it changes anything. My LLM Security Middleware came from wondering how to trust systems that can be manipulated through language. And StoryBuddy reminded me that even a great model isn't useful if someone has to wait too long for it to respond.

CHAPTER 03 / FIELD NOTES

A few things
I've learned.

Resumes make experience sound neat and linear. The useful lessons usually come from the messy parts.

NOT A TECH STACK. MORE LIKE A WAY OF THINKING.
Nº 01

If someone still has to copy-paste for hours, it's not done.

HGrid made the value of automation tangible. The strongest feature wasn't the most complicated one. It was the one that gave staff their time back.

Back to the HGrid story ↗
Nº 02

Silence is part of an interface.

When you're building a conversation with a physical robot, a three-second gap can change the whole experience. State management isn't just technical; it's how the interaction feels.

Nº 03

A detection isn't the same thing as understanding.

Whether it's a suspicious IP or an attempted jailbreak, the hard part is context. I like finding out which signal matters and what to do next.

Nº 04

Trying to be “just one thing” never really worked for me.

Robotics taught me communication. Security taught me skepticism. Software engineering taught me to ship. I want to keep using all three.
