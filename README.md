# Aarav Jain: Portfolio

A static site. No build step.

## Files
- `index.html`: the whole site (styles and scripts are inside)
- `Aarav_Jain_Resume.pdf`: linked from the Resume button in the nav

## Deploy to GitHub Pages (aadraxe.github.io)
1. Copy these files into the root of your `aadraxe.github.io` repo, replacing the old `index.html`.
2. Commit and push:
   ```
   git add index.html Aarav_Jain_Resume.pdf README.md
   git commit -m "Update portfolio and resume"
   git push
   ```
3. Wait a minute, then open https://aadraxe.github.io and hard-refresh (Ctrl+Shift+R / Cmd+Shift+R).

## Updating the resume later
Replace `Aarav_Jain_Resume.pdf` with a new file of the same name and push. No HTML changes needed.
